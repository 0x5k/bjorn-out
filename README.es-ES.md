# WiFi Network Switcher para Bjorn

**Cómo usarlo:**
1. clona este repo en bjorn
2. `cd bjorn-out`
3. `chmod +x bjorn-out.sh`
4. `sudo ./bjorn-out.sh`

**¿Qué hace?**

Este script automatiza el proceso de cambiar la red WiFi de tu dispositivo a un SSID especificado para el proyecto https://github.com/infinition/Bjorn.

Es útil para escenarios donde desees conectarte a una red Wi-Fi diferente.

**Nota:** el proyecto está bajo desarrollo.
